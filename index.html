Command format

How a level gets turned into bytes for the device. Don't know? Connect, then tap Find the right setting.

Template is hex bytes. {v} = level as one byte (0 to max), {v16} = two bytes, {sum} = checksum of the bytes before it, {chk} = same but skipping the first byte, {vt} = level written as text digits. Start with text: to send plain text, e.g. text:SET {v}
